# Локальный запуск

## Требования

- Node.js 18 или новее
- MySQL 8+ (либо совместимая MariaDB)
- npm

## Установка

1. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/Tunez666/diplome.git
   cd diplome
   ```

2. Установите зависимости:

   ```bash
   npm install
   ```

3. Создайте локальную базу данных MySQL. Публичный дамп с пользовательскими данными в репозитории не хранится.

4. Создайте файл `.env` на основе `.env.example` и заполните собственные значения:
   - `DB_HOST`
   - `DB_USER`
   - `DB_PASS`
   - `DB_NAME`
   - `SESSION_SECRET`
   - `SMARTCAPTCHA_SERVER_KEY`
   - `SMARTCAPTCHA_SITE_KEY`

   Для `SESSION_SECRET` используйте длинное случайное значение. Не публикуйте файл `.env`.

5. Импортируйте в созданную БД собственную схему и тестовые данные, если они у вас есть.

6. Запустите приложение:

   ```bash
   npm start
   ```

По умолчанию сервер слушает порт 8080. Его можно изменить через переменную `PORT`.
